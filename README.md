# developerhandbook

***About***
Template for a document including all the stuff which is needed for onboarding to a software project 
and further information nneded to be productive as fast as possible, from the view of a software developer.

# Introduction

For a software project, there are four cornerstones of essential information:

![Cornerstones](/images/en/en-cornerstones.png "Cornerstones")

- **Setup environment**: How do I setup my environment for implementation to become as fast productive as possible?
- **Architecture description**: What'S the software architecture of the system which I should work on?
- **Rules, processes**: Which rules and processes are defined in the project and are important for development? These could be for example development guidelines or build- and deployment processes.
- **Howtos**: Which use cases Welche Use Cases, tips and tricks can help me for my daily work?
